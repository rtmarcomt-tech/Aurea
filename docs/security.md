# Security checklist

- [ ] One-time administrator bootstrap; no hardcoded credentials.
- [ ] Argon2id password hashing with reviewed parameters.
- [ ] Opaque random session identifiers; store only token hashes.
- [ ] Session expiry, rotation, logout and administrator-initiated revocation.
- [ ] HttpOnly, Secure in production, SameSite cookies.
- [ ] CSRF protection for state-changing browser requests.
- [ ] Server-side authorization on every admin query and mutation.
- [ ] Zod validation at every untrusted input boundary.
- [ ] Rate limiting for authentication, contact and media uploads.
- [ ] Strict upload allowlist, byte limits, signature detection and safe image re-encoding.
- [ ] Storage keys generated by the server; no user-controlled filesystem paths.
- [ ] Output encoding; no arbitrary HTML or script injection in page editors.
- [ ] Security headers and HTTPS-only production deployment.
- [ ] Redacted logs; never log credentials, session tokens or secrets.
- [ ] Audit events for security-sensitive actions.
- [ ] Off-server encrypted backups and successful restore drills.
